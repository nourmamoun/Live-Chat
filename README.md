# 💬 WebSocket Chat App

A simple real-time chat application using Python WebSockets and a browser frontend.

## 🚀 Features

- Real-time chat using WebSockets
- Web-based UI with HTML/CSS/JS
- Broadcast messages to all connected clients
- Username prompt for personalized chatting
- Lightweight and easy to set up locally
